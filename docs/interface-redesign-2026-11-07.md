# v3.4.0 — whole-interface aesthetic revision

## What changed

The earlier asset passes retained Gemini's centered logo, navy glass cards and screen structure. This revision changes the visual grammar and the actual page composition: local Barlow Condensed / IBM Plex Sans typography; paper, ink, forest and brass tokens; ruled surfaces and registers; compact masthead; a persistent club dossier/navigation rail; and a separate dark broadcast island.

Home is an asymmetric career-entry spread with numbered mode rows, saved-career entry, a credited venue photograph, restrained tutorial status and collapsed cost/release controls. The authentic kit archive remains sourced and retains its theme callbacks. Club selection, standings, scouting/free agency and bid negotiation use readable directories/registers. Match transport, scorebug, pitch, live notes and stadium controls have been reorganized. Squad/tactics use a roster sheet and flat tactical diagram. Staff setup, interviews, player talks, press editorial/evidence, inbox, international reports, handbook and tutorial use coordinated dossier/document treatments.

This is a presentation release. Simulation, AI requests/consequences, roster/source datasets, contracts, save schemas and audio scheduling were not changed. A deterministic World Cup selector catalog is memoized to avoid rebuilding its static presentation list on each render. The release retains the previous game-system requirements and their unfinished full-world/atmosphere scope.

## Existing checks and observed presentation evidence

- TypeScript and the complete existing regression suite pass: 33 files, 186 tests.
- Home was inspected at 390×844 and 1440×900 CSS pixels using managed captures, then real saved-career match/workspace and market surfaces were inspected in the browser.
- Phone-width browsing frames exercise actual CSS media queries, not merely a narrowed desktop div. At 320 CSS pixels the corrected masthead has no measured brand/control collision and the market has no page-width overflow. At the earlier 388-pixel frame all eight mobile workspace destinations remained available.
- All five local font faces loaded. Packaged font files were converted to actual WOFF2; their combined bytes dropped from 789,584 to 289,116. Font licences are retained. Venue/kit/crest attribution remains explicit.
- One independent read-only integration review found terminal dark-on-dark text, several unmatched legacy state/identity colour pairs and the 320-pixel masthead collision. These were corrected with explicit inverse scope, semantic nationality/trophy/switch colours and a smaller-width masthead rule. Live-notes ARIA remains boolean. Momentum display is rounded only for readability.
- Terminal recheck: visible light log messages (`rgb(244,243,233)`) on the dark forest surface (`rgb(17,44,35)`). Market nationality badges use ink on the light surface. No paid AI requests, new fixtures or financial actions were invoked for the visual checks.

## Limits

This is not a benchmark on Steve's actual iPhone, a claim of complete accessibility certification, proof that every legacy long-term game system is finished, or a claim that the game is now universally fun. Existing provider/network/hardware-dependent behavior remains. The new venue photograph is Wembley in 2011, not a selected-club stadium or a current-season match. No new player likenesses or manufacturer-accurate full-kit textures are claimed. Publication remains a separate action; this version is saved for Preview.
